## Метрики
### Команда для получения основных метрик метрик:
```bash
db.adminCommand({ dbStats: 1, scale: 1024 * 1024 });
```
### Метрики для отслеживания:
1) Баланс чанков - распределение между шардами
2) Нагрузка на шарды - CPU, память, connections
3) Распределение категорий - концентрация товаров в разных категориях
4) Паттерны запросов - частота и тип операций по категориям

### Механизмы для управления данными:

1) Sharded Cluster Balancer - Разделение больших шардов можно сделать используя выделение
   подкатегорий товаров на основе их атрибутов
2) Dynamic Chunk Splitter - автоматическое разделение горячих чанков
